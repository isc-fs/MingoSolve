ISC MingoSolve: three directions

Same screen in all three: paste a problem (or browse a topic), the best-matching solver opens with the values from the text already filled in, and the missing one is solved live. All use ISC tokens (green #064229, gold #FFB81D, Jost + IBM Plex), rounded 14 to 22 px corners, frosted glass over a soft textured backdrop. None looks like MingoCAN's flat green-and-yellow.
